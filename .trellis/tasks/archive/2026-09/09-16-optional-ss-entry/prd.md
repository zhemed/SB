# SS-2022 入口改为可选（默认不装），菜单[8] 变为可选功能

## Goal

v3.0.1 里 Shadowsocks-2022 入站是**默认安装**的第二个客户端入口。它在我们自己的拓扑里没人连
（客户端入口是 hy2），等于白白多一个公网监听面。本任务把它改成**可选能力**：新建安装只装
hysteria2，想用时在菜单【8】里显式启用。发布 **v3.1.0**。

## Requirements

### ① 默认不装

- 新建安装：只创建 hysteria2 入站，只问 hy2 端口，只生成 UUID；不再询问 SS 端口、不再生成 SS 密钥。
- 安装提示里的防火墙说明只提 `${port_hy2}/udp`，并说明「如需 SS-2022 入口，在菜单[8]启用后放行其 TCP 端口」。

### ② 菜单【8】= 可选功能

```
可选功能
  1：Shadowsocks-2022 入口   当前：未启用 / 已启用（端口 443）
  2：上游/中转               当前：未配置 / <server>:<port>
  0：返回主菜单
```

SS-2022 入口子菜单（自包含，改端口/改密钥不再散落在【5】【6】）：

```
Shadowsocks-2022 入口
  1：启用（默认随机端口，可选自定义）
  2：停用
  3：更改端口
  4：更改密钥
  0：返回
```

- 启用：选端口（回车/1 = 随机 10000-65535、2 = 自定义，与安装时的端口逻辑一致）→ 生成密钥
  → 候选配置（补入站 + 补 UDP 阻断规则）→ `commit_config` → 刷新分享文件。
- 停用：确认后移除入站与规则 → `commit_config` → 刷新分享文件（并删掉 `ss.txt`）。
- 改端口/改密钥：只在已启用时可用，否则给明确提示。
- 入站的 `listen` 与 hy2 入站保持一致（从现有配置里读，而不是重新探测）。

### ③ 客户端产物跟随入站存在与否

- 未启用：不生成 `ss.txt`（并清理遗留的）、`sbox.json` 无 SS 出站、`clash.yaml` 无 SS 条目、
  聚合文件只有 hy2；Clash 分组 `[hysteria2, DIRECT]`，sing-box selector 只剩 hy2。
- 已启用：与 v3.0.1 完全一致（SS 在前、hy2 在后）。

### ④ 修复/升级不擅自改拓扑

- 配置里有 `ss-sb`：**保留**（端口与密钥原样提取）。
- 配置里只有旧的 `socks`/`socks5-sb`：**继续迁移**为 SS-2022（重新生成密钥并提示更新客户端）——与 v3.0.1 相同。
- 配置里两个都没有（新默认形态）：修复后仍然没有，**不得**自动补上。
- 升级到本版本的机器：跑菜单[2]修复不会丢掉已在用的 SS 入口。

## Acceptance Criteria

- [ ] 新建安装路径渲染出的配置只含 hysteria2 入站；真实内核 `check` 通过且能真启动。
- [ ] 菜单[8]启用 SS 后：配置含合法 `ss-sb` 入站与 UDP 阻断规则，服务重启后仍 active；`ss.txt` 与客户端配置同时出现。
- [ ] 停用后：入站与规则消失、`ss.txt` 被删除、客户端配置回到只有 hy2，服务仍 active。
- [ ] 连续启用两次不产生重复入站/重复规则（幂等）。
- [ ] 修复：`ss-sb` 形态原样保留；`socks` 形态仍迁移；hy2-only 形态不补齐 SS。
- [ ] 端口默认随机、可选自定义；自定义端口被占用时有明确提示。
- [ ] `bash scripts/build.sh && bash tests/verify.sh` 通过（shellcheck 0.10.0 及以上）。
- [ ] 真实内核复验：hy2-only 真启动 + 启用后的 SS 真握手 + 中转链路（与上轮同法）。
- [ ] 版本四处同步为 `3.1.0`，`scripts/check-version-bump.sh` 通过；README 与四层规范同步。

## Non-Goals

- 不引入第三个协议，不改 hy2 的既有行为。
- 不改上游/中转的既有语义（仍是 state file + 每次渲染重注入）。
- 不为「SS 入口未启用」单独建状态文件：**配置里有没有 `ss-sb` 入站就是唯一真相**。

## Notes

- 用户已拍板：菜单合并进【8】；老机器保留现状；启用时端口默认随机、第二项自定义。
- 这次改动的技术风险低于上一轮（SS 路径本身已实测可用），主要成本在 jq 选择器与测试钉死串。
