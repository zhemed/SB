# implement.md — 脚本本体审计（5.1.1）

范围：`src/` 十一个模块 + `sb.sh` + `tests/`。逐模块读（3 个并行只读审计 + 我本人重点段）。
下面按严重度列**真缺陷**，标注修没修。

## 高危（1，我造成的，已修）

1. **服务单元归属标记被删掉**：`src/40-service.sh` 两个生成器里的 `# Managed by sb.sh` 是**生成文件的内容**，
   被"删除所有注释"一并删了。后果：装完之后所有归属/可修复判定恒假 → 下次运行直接拒绝继续、
   安装/修复/卸载/证书部署全部被拒，只能手工删单元文件。已加回，并补行为测试（`write_service_definition`
   产物必须通过 `systemd_unit_is_owned`/`openrc_unit_is_owned`）+ 门禁钉子（该行必须恰好出现 2 次）。

## 中危（9，已修）

2. 设置中转：`relay.conf` 在 `commit_config` 之后才写，写失败只打红字仍返回成功 → 配置在走中转、状态文件缺失。
   已改成事务式：先写状态文件，提交失败就回滚状态文件。
3. 清上游：先提交再删状态文件，删失败只提示 → 残留的 relay.conf 会在下次重写时**静默把中转装回来**。
   已改成先删（失败即中止，不改配置），提交失败再写回。
4. 手改上游出站的探测从 `type == "shadowsocks"` 收成 `type == "socks"`（5.1.0 我改的）→
   5.0.x 遗留的 relay 出站不再被识别，重写时静默丢掉且无提示。已改成按 `tag == "relay"` 认。
5. `print_socks_entry_share` 照打文件里的旧链接，还无条件声称"已写入" → 改完口令后复制到旧链接。
   已改为按当前端口/口令/主机/IP 核对，不一致就只指向菜单[3]。
6. `clash.yaml` 里 socks 用户名/口令未加引号 → 纯数字口令被 YAML 解析成数字（mihomo 认证失败）。
   已加引号。
7. `result()` 多处静默 `return 1`（IP 两文件不一致、读不到 hy2 口令/端口/证书路径、指纹异常）→
   用户只看到"刷新失败"却无原因。已逐条补明确错误信息。
8. ACME 注册成功的判据校验"当前生效证书"而非"这次装进暂存区的那份" → hook 失败回滚后仍判成功。
   已加暂存证书与生效证书的指纹一致性比对。
9. crontab 过滤用 `|| true` 吞掉管道状态 → 过滤出错时整表被替换、用户的定时任务静默丢失。
   已改为落临时文件 + 检查每级退出码（≥2 即中止，保留原 crontab），四处调用点全部覆盖。
10. ACME 流程里"在 Token 提示处直接回车/EOF"被当成失败 → 白删再恢复现场 + 多重启一次。
    已用独立返回码 3 表示"未做任何改动即取消"，调用方跳过回滚。

## 低危（16，已修）

11. relay 出站缺 `"network": "tcp"`（服务端会收下 UDP 再被落地机丢弃 = 黑洞）：渲染路径与菜单路径都补上。
12. `entry_rules` 缺 `+=$'\n'` → 生成 JSON 出现 `},      {` 黏行。
13. `ipuuid` 的 `save_server_ip …; break` 吞掉写盘失败 → 把"写不进 /etc/sb"报成"探不到 IP"。
14. `socks_enabled` 判定口径与菜单不一致 → 口令字段被改坏时会把还能用的 `socks5.txt` 删掉；已统一按入站存在判定并明确报错。
15. 切到 ACME 后残留旧的 `SHA256.txt`（无人读，会误导手工 pin）：切换时删除。
16. `sbshare` 临时文件前缀不合规范、修复流程清理不到：改名 `.socks5.txt.*` / `.hy2.txt.*` / `.jhdy.txt.*` 并加入清理清单。
17. 卸载确认的 `readp` 无失败处理、取消无提示：已补 `|| return 1` 与"已取消"提示。
18. 单元里 `ExecReload=/usr/bin/kill` 写死路径且 procps 不在依赖清单：改为 `/bin/kill`。
19. 死代码：`installed_config_is_valid`、与 `remove_acme_renew_cron` 逐字节重复的 `remove_current_acme_cron`、重复的 `local socks_clash_member=`。
20. ACME hook 回滚后不再确认服务是否起来（`|| true` 吞掉）：失败时向 stderr 打一条可被 cron mail 抓到的提示。
21. 退役入口警告措辞不准（说"下次改端口/凭据就会移除"，实际只有修复/重装的重写路径会）：改为"只有用菜单[2]修复或重装重写配置时才会移除它"。
22. 改 SOCKS5 密码时"未启用"的提示与改端口不一致：已对齐。
23. 证书文件缺失时的提示不指路：补"请先用菜单[2]修复生成"。
24. `chooseport` 重试循环无出口、读失败会死循环空转：加 `输入0取消` + 读失败按取消（返回 2），两个菜单调用点与安装流程都处理。
25. `hostname` 未校验就写进 JSON/YAML/链接：读取失败或字符非法时回退 `sb`。
26. 中断遗留的 `.sb.json.XXXXXX` 候选无人清理：加进修复流程的清理清单。

## 记录在案、本次未改（4）

27. 主菜单每 300s 缓存过期后会串行探测最多 6 个 IP 回显服务（每个 5s 超时），出网被墙时菜单最多卡 ~30s。
    属交互设计改动，先不动。
28. 菜单里的"改配置 + 重启"不持 ACME 锁，与 6 小时一次的续期回调撞车时可能把好配置判失败并回滚
    （提示是诚实的，影响低）。
29. `v6only` 用 `grep -oP`（GNU 专有）；正常流程在 Alpine 会装 GNU grep，故实际可用。
30. 中转只做 TCP 建连探测、不验 SOCKS5 认证：探测通过也可能是密码错。已在提示里列出这种可能，
    未改成强制握手探测（避免把落地机出网故障误报成密码错）。
