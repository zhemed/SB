## 已确认并修掉（带测试或门禁钉子）

1. **`chooseport` 的重试循环没有出口**（`src/20-ports.sh`）
   - 现象：端口非法或已被占用后进入重试；该提示既没有取消键，`readp` 的失败也没处理。
     按 Ctrl-D（输入结束）时 `port` 保持原来那个非法值，条件永远为真 → **死循环空转**，
     只能 Ctrl-C 或杀进程。
   - 修法：提示加 `输入0取消`，`readp ... || return 2`，选中 0 也返回 2；
     两个管理菜单调用点（改 hy2 端口、改 SOCKS5 端口）与安装流程都按状态码处理取消。
   - 测试：`tests/unit.sh` 两条用例（冲突端口可取消、读失败按取消）；门禁钉住提示文本。
2. **`hostname` 未校验就写进产物**（`src/00-bootstrap.sh`）
   - 现象：`hostname=$(hostname)` 之后直接用于 JSON/YAML 的 tag 与分享链接；主机名含
     引号/反斜杠等字符时会生成非法配置（真会被内核 `check` 挡住，但那时安装已经走到一半）。
   - 修法：读取失败或字符集不合法时回退 `sb`。门禁钉住这两行。

## 记录在案、暂不修（要动之前先问）

3. **主菜单每 5 分钟可能卡 ~30 秒**：`menu` 每次重绘都调 `v4v6`，缓存 300s 过期后会
   串行请求最多 6 个 IP 回显服务（每个 `--max-time 5`）。出网被封的机器上表现为"菜单卡住"。
   彻底解决要改成"只有缓存缺失或用户主动刷新时才探测"，属交互设计改动。
4. **`v6only` 用 `grep -oP`**（GNU 专有）：依赖安装会在 Alpine 装 GNU grep，正常流程可用；
   任何在依赖安装之前调用它的路径会静默退化。
5. `ipuuid` / `insport` 的 `readp` 失败会按"回车默认"继续（IPv4 / 随机端口）——与提示写的
   默认值一致，判为可接受。
