## 执行范围（按"彻底"= 项目里不再有 SS）

1. 上游/中转那一跳：出站从 `type: "shadowsocks"` 换成 **落地机的 SOCKS5 入口**
   （`type: "socks"`，用户名固定 `sb`，密码就是落地机菜单[8]第 1 项生成的那个）。
2. 删掉 `RELAY_METHOD`、`valid_ss_password`、`2022-blake3-aes-256-gcm` 及它们的用例。
3. 菜单/提示里不再出现该协议的名字（含"旧入口"相关提示，改成不点名的说法）。
4. 门禁新增硬性禁入：`sb.sh` 与 `src/` 里出现 `RELAY_METHOD` / `2022-blake3` /
   `valid_ss_password` / 协议名本身，直接红。
5. README、规范同步；产物（`src/`、`sb.sh`、README、规范）零命中，历史任务目录保留原样。

## 代价（已在 README 写明）

- 这一跳不加密（与客户端入口同一取舍）；
- 只承载 TCP，UDP 不走这一跳（与旧设计一致）；
- 旧的 `relay.conf`（44 位 base64 密钥）会被判无效，提示"请在菜单[8]里重新设置一次"。
